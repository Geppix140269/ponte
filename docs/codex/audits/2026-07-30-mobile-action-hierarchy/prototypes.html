Action component · interaction states

Every state distinguished by shape, position, text and fill weight — never colour alone (§18). The row action, across the recommended Direction B, plus the shared disabled/loading/completed forms.

Disabled is not colour-only: it changes fill (sunken), border (rule-strong), cursor, and carries a reason. Loading swaps the glyph for a spinner and the verb for “Saving”. Completed removes the action entirely and replaces it with the member-confirmed state marker — the action is gone because the work is done.

One desktop adaptation · Direction B

Mobile is the approval authority. On desktop the same system widens: the register becomes two columns of white working surface, the field name returns to a left key column, actions stay right-aligned and blue. No new pattern — the mobile system, given room.
